# Liu Ice-cream

> 做本地优先的创作与知识工具；平时折腾 LLM 训练与推理。

## 在做的事

- **音芽 yinya** — 面向零基础用户的音乐积木：四声部创作、即时试听、播放跟随、本地作品与 WAV / MP3 导出 · `JavaScript`
- **拾章 story-atlas** — 本地长篇小说资料助手：人物关系、状态时间线、文风工作台、纸质感阅读器 · `JavaScript`
- **段落匣 paragraph-box** — Flow Launcher 的本地 Markdown / TXT 段落搜索，支持目录别名与带出处摘录 · `Python`
- **源笺 yuanjian** — 把收藏的资料转化成可复用的研究材料 · `Python`

## 关注

本地优先 · 个人知识管理 · 写作工具 · LLM 训练与推理（数据选择 / 推测解码 / 推理服务）

## 技术栈

Python · JavaScript · PyTorch / transformers · SQLite
